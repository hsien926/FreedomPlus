# FreedomPlus 1.4.0 发布说明

**公开版本：1.4.0 · versionCode：150 · 包名：io.github.fplus**

## 本版重点：评论长按不再误开设置

在抖音 40.6.0 的真机现场，评论行和视频区均使用 `LongPressLayout`。原逻辑把评论行的局部坐标当成视频上半屏，同时评论生命周期方法已迁移到父类，导致面板状态登记未生效。修订后：

1. **隔离手势来源**：仅实际视频 ViewHolder 父链可以建立模块手势，评论原生复制放行。
2. **修正继承方法挂接**：沿继承链定位 `onViewCreated` 实际声明类，只处理目标评论 Fragment 实例。
3. **跟踪实际评论面板**：登记 `CommentNestedLayout`，不再用收起后仍显示的外层 `FrameLayout` 判断状态。
4. **约束回调会话**：原生长按拦截绑定有效视频会话，延时入口再次检查来源与面板可见性。

评论收起后，长按视频上半屏仍正常打开模块设置。长按时长、区域阈值、左右边缘快进规则、配置、依赖和权限不变；已有媒体、界面、过滤、WebDAV、高刷及兼容逻辑保留。

## 版本与覆盖安装

本次发布为 **1.4.0 / 150**，包含最新真机修订，不是早期失效的 1.4.0 / 149。内部候选名 1.4.1 统一为公开名称 1.4.0，版本代码保持 150，正式签名不变。

同签名旧版可覆盖安装并保留配置。安装后强制停止并重开抖音，确保宿主重新加载模块；不需要清空应用数据。不同签名包及 Debug 包不能直接覆盖本维护线正式 APK。
