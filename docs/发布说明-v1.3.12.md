# FreedomPlus v1.3.12｜高刷新率一体版与完整功能说明

FreedomPlus 是面向抖音的 Xposed / LSPosed 功能增强模块，提供广告拦截、视频与图文下载、界面精简、播放交互调整和高刷新率支持。

**本版重点修复 Release 构建中高刷新率 Hook 回调被 R8 裁剪的问题**，保留应用侧与小米 PowerKeeper 系统侧的一体化实现。以下分别列出本次修复、当前保留功能及适配边界；功能总览不代表这些功能均为 v1.3.12 新增。

## 本次修复

- **修复高刷新率回调被裁剪**：补充 `beforeHookedMethod` / `afterHookedMethod` 保留规则，避免外部调用的 Xposed 回调被当作未使用代码移除。已核对发布 APK，应用侧与系统侧高刷回调执行体均存在。
- **沿用一体化高刷实现**：抖音应用侧与小米 PowerKeeper 系统侧处理继续集成在同一个 APK 中，无需另装桥接模块；运行时 Kotlin / Java 逻辑与 v1.3.11 一体版相同。
- **保持配置与签名连续性**：沿用原高刷开关、首次迁移及共享状态同步逻辑，沿用现有发布签名。
- **版本更新**：`1.3.12`，`versionCode 148`，包名 `io.github.fplus`。

## 完整功能总览

### 1. 广告拦截与内容过滤

- **广告拦截总开关**：新装默认开启，可在模块设置中关闭。
- **小程序 / 小游戏广告处理**：按广告 SDK 类型拦截激励、插屏、横幅、信息流及开屏等请求；这里的“开屏”指对应 SDK 的广告类型，不代表已验证拦截所有抖音启动广告。
- **插屏广告处理**：阻断目标创建链路，并在匹配到接口时通知调用方广告加载失败。
- **激励视频处理**：缩短目标广告的本地计时与关闭等待，保留原有奖励处理链路；实际奖励发放以目标业务返回结果为准。
- **信息流广告处理（实验性）**：在数据落表阶段剔除广告项，并在普通、可玩和互动可玩广告 ViewHolder 的绑定入口补充拦截。仅绑定阶段拦截的条目可能留下空白页；实际投放环境下的效果仍需验证。
- **视频过滤设置（版本相关）**：保留直播、广告、图文、长视频、推荐卡片、推荐商家、空文案及自定义文案关键字的配置与旧版实现。40.6.0 下非广告过滤的旧入口缺失，不能视为全项可用，详见下方适配边界。
- **弹窗关键字过滤**：按弹窗文本关键字关闭目标弹窗，可选显示关闭提示。

### 2. 视频、图文与音频下载

- **视频播放源下载、图文图片保存、背景音乐下载**。
- **视频编码选择**：提供 `Auto`、`H264`、`H265` 播放地址优先级；目标地址缺失时按已有降级链选择，不是把视频重新编码。
- **自定义文件名与创作者目录**：可修改文件名，并按创作者单独建立文件夹。
- **下载进度展示**：支持弹窗进度或通知栏进度。
- **复制链接唤起下载弹窗**：可开启“分享 → 复制链接”下载入口，沿用全屏播放场景的处理。
- **文案复制**：在下载选择弹窗中直接复制当前作品文案。
- **评论区图片 / 视频保存**，以及**表情包、相关表情保存**。
- **图片格式兼容**：图文下载时识别部分 VVIC / HEIC 内容，调用抖音内置解码器转为 JPEG，改善相册或电脑打不开的问题；解码器缺失或解码失败时不保证转换成功。
- **媒体库刷新与反馈**：本地保存后通知媒体库更新，支持相关保存操作的可选震动反馈。
- **本地分类存储**：下载内容保存在外置存储器的 `Download/Freedom` 下，按视频、图片、音乐等类型分类。

### 3. 界面精简与外观调整

- **首页控件半透明**：顶部导航、视频控件、视频右侧控件、底部导航分别提供 `0–100` 调整值；右侧控件透明度受整体视频控件值约束。
- **顶部标签隐藏**：按自定义关键字隐藏顶部选项；开启后会限制左右滑动切换。
- **底部标签隐藏**：按自定义关键字隐藏底部选项。
- **底部加号按钮调整**：提供保留拍摄入口、禁止拍摄、移除按钮三种处理方式。
- **视频右侧控件隐藏**：按控件类型或文本关键字处理头像、喜欢、评论、收藏、分享、少推荐、音乐等项目。
- **悬浮挑战 / 评论贴纸移除**：处理部分作品中的悬浮挑战与评论回复控件。
- **底部播放控制栏移除（旧版相关）**：保留针对旧版单一控制栏容器的设置，40.6.0 下已不适用。
- **评论区颜色模式**：提供浅色、深色及跟随主题三种模式；同时保留评论区展开后的搜索入口精简处理。

### 4. 清爽模式与沉浸播放

- **清爽模式**：隐藏主要视频控件及首页顶、底部控件；暂停视频时恢复相关控件显示。
- **清爽模式长按菜单**：提供清爽 / 普通模式切换、评论、收藏、分享、下载、视频信息和模块设置入口；菜单项按已启用功能显示。
- **长按区域选择**：可选择上半屏或下半屏响应。若已开启“长按上半部分打开模块设置”，清爽模式菜单改由下半屏响应，避免两个入口同时触发。
- **视频信息查询**：查看作品发布时间与属地信息；属地查询依赖网络接口，接口异常时会显示获取失败。
- **全屏沉浸播放**：可分别隐藏状态栏与导航栏，保留横屏播放的独立沉浸处理。部分内容可能出现裁切或拉伸。

### 5. 播放、手势与消息体验

- **自动连播**：沿用抖音连播能力，可增加首页连播按钮，也可设置启动时默认开启。
- **双击视频响应类型（版本相关）**：保留“打开评论”与“点赞视频”两种选择；旧双击拦截入口在 40.6.0 下未命中，不保证切换后能阻止原生点赞。
- **手势误触复确认**：底部首页操作、头像关注等目标操作增加确认弹窗。
- **长视频时长提示**：切换到达到 10 分钟阈值的视频时提示时长。
- **消息防撤回（保留项）**：保留防撤回与“保留自己撤回的消息”设置。设置页已标注“失效不修”，本版不宣称恢复其在所有抖音版本上的可用性，也不恢复已经被服务端替换的消息内容。

### 6. 高刷新率（实验性）

- **同一个开关控制两条路径**：应用侧窗口 / 公开 Java Surface 帧率请求，加上小米 PowerKeeper 系统侧正常视频场景请求。
- **按当前屏幕能力选择目标**：在当前物理分辨率下请求最高有效刷新率，不硬编码 120 Hz。
- **新装默认关闭**：升级时首次迁移主抖音内的既有开关状态；共享状态建立后不再由旧本地值重复覆盖。
- **系统侧范围收敛**：仅处理主抖音、默认主屏、正常视频场景的有效低刷新率请求，不改其它应用、副屏或其它场景请求。
- **保留系统约束**：不写全局刷新率键，不禁用 PowerKeeper、Joyose 或温控服务；保留省电、中等及以上热状态限制，以及原方法内部的用户上限和其它系统投票。
- **不是视频补帧**：不改变视频源帧数、解码时间戳或播放速度。高刷新率显示不等于每条视频都有相同数量的不同画面。

### 7. 定时退出与 WebDAV

- **定时退出 / 空闲退出**：分别设置运行时间与无操作时间，单位为分钟；低于 3 分钟的对应计时不执行。
- **保留应用后台**：可将退出行为改为切换后台；原有直播间空闲计时暂停处理继续保留。
- **WebDAV 媒体上传**：配置服务器后，可在下载弹窗中选择将视频、图片或背景音乐下载后上传至 WebDAV，沿用媒体分类目录。
- **WebDAV 多配置**：支持连接测试、保存配置历史、选择与删除历史配置。
- **范围说明**：当前 WebDAV 是媒体文件上传功能，不是模块配置备份与恢复。

### 8. 模块入口与管理

- **长按上半屏打开模块设置**：默认开启，避开左右边缘的长按快进区域；可关闭以恢复原行为。
- **模块应用入口**：查看框架加载状态、本机抖音版本与本地适配提示，并跳转模块设置。
- **保留旧设置入口**：侧边栏 / 加号弹窗入口沿用已有实现，是否出现取决于抖音版本中的对应界面是否仍存在。
- **桌面图标显示 / 隐藏**。
- **本地更新日志与类匹配日志查看**，支持清除 DexKit 匹配缓存后重新定位。
- **下载目录管理与旧目录迁移**：保留旧 `DCIM/Freedom` 迁移到 `Download/Freedom` 的逻辑；模块应用的清空操作会同时清除本地配置与下载内容，并复位共享高刷开关。
- **内置 OTA 已移除**：更新日志与适配列表随包分发，不后台检查远程版本。媒体下载、WebDAV 上传和属地查询仍会按功能需要联网。

## 安装与启用

1. 安装本次提供的 **Release APK**。
2. 在 LSPosed 中启用 FreedomPlus，主抖音作用域选择 `com.ss.android.ugc.aweme`。
3. 如需使用小米系统侧高刷，追加 **电量与性能** `com.miui.powerkeeper` 作用域；不需要另装桥接模块。
4. 打开一次 FreedomPlus，按系统版本授予保存媒体所需的文件 / 存储权限。
5. 强制停止并重新打开抖音。在抖音内长按上半屏进入模块设置，按需启用功能。
6. 修改高刷开关后重新启动抖音；首次追加 PowerKeeper 作用域，还需重载其主进程。整机重启可重载相关进程，只重开抖音不会让已经运行的 PowerKeeper 加载新增 Hook。

**升级说明**：同签名旧版可覆盖安装并保留配置；其它来源若签名不同，不能直接覆盖。不要为升级使用“清空下载目录”操作，该操作也会清除本地配置。

## 适配与验证边界

- **环境**：以 Root + LSPosed、64 位主抖音为基准；32 位抖音不作兼容保证。模块最低构建要求为 Android 7.0 / API 24，不代表每项功能均已在该系统版本验证；公开 Java Surface 帧率处理要求 Android 11 及以上。
- **本地适配列表**：包含 `28.0.0–30.3.0` 中列出的版本及 `40.6.0`，不是 `28.0.0–40.6.0` 全区间连续适配承诺。
- **40.x 修复沿用**：保留 40.6.0 启动 / 下载地址解析修复，以及针对 40.8.0 的 PagerAdapter 数量失配修复；这不等于完成了上述版本的全功能回归。
- **高刷验证**：现有构建与检查记录显示，42 项核心逻辑测试通过，发布签名及高刷回调执行体核验通过；已有小米设备安装使用反馈确认抖音界面高刷生效。该反馈不扩大为所有 ROM、所有视频源或重启持久性均已验证。
- **小米系统侧基准**：切入点依据已核对的 PowerKeeper `4.2.00`。其它 ROM 若类、方法或必需字段不匹配，会记录日志并保留原系统策略。
- **信息流广告**：测试环境未取得实际广告投放下的拦截成功证据，继续标为实验性；小程序 / 小游戏的部分 `operate*` 展示入口在 40.6.0 下缺失，由其它匹配到的拦截链路处理。
- **旧版视频过滤**：40.6.0 下旧推荐 / 关注数据入口缺失；新 Adapter / ViewHolder 方案处理的是广告，不代表直播、图文、文案等非广告过滤已经恢复。
- **历史保留代码**：语音评论保存工具仍在源码中，但当前未接入可触发入口，不列为本版已可用功能；“崩溃容错 / 去插件化”设置处于暂存区，当前设置页未展示。
- **极速版 / 火山版**：保留原加载规则，但未完成完整功能验证；两者不使用主抖音的共享系统侧高刷开关。
