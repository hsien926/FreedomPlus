# 构建指南

当前源码为 **FreedomPlus 1.4.0 / 150**；使用 JDK 17、Android SDK 34、Gradle Wrapper 8.9。AGP、Kotlin 与依赖的实际版本以[版本目录](<../gradle/libs.versions.toml>)为准。

## 工程结构

[ktutils](<../ktutils/build.gradle>)、[xpler](<../xpler/build.gradle.kts>)为普通源码目录，不是 Git 子模块。其它现用模块由[settings.gradle](<../settings.gradle>)注册，不删除宿主占位编译模块或兼容分支。

构建本次正式版本时使用 [v1.4.0 标签](https://github.com/hsien926/FreedomPlus/tree/v1.4.0)，或从 [Release](https://github.com/hsien926/FreedomPlus/releases/tag/v1.4.0) 获取对应完整源码 ZIP。日常 main 与后续版本可能继续变化，不用未签名 CI 产物替代正式 APK。

## 本地配置

维护环境已有 SDK 与原正式签名，继续使用，不重新生成密钥。

源码归档不含私密配置。独立构建需提供 local.properties 的 SDK 路径；正式签名还需 keystore.properties 与其对应密钥库。未配置正式签名时 Release 产物未签名，不能作为原维护线覆盖包。

```properties
sdk.dir=D\:\\Tools\\android-sdk
```

```powershell
$env:JAVA_HOME = 'D:\Tools\jdk-17'
$env:ANDROID_HOME = 'D:\Tools\android-sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
.\gradlew.bat --offline --no-daemon --console=plain --max-workers=2 :core:testDebugUnitTest :app:assembleDebug :app:assembleRelease
```

已有依赖缓存时可离线构建；首次独立环境需先准备 SDK、Wrapper 与 Maven 依赖。

## 产物

- Release：`app/build/outputs/apk/release/freedom+_1.4.0.apk`。
- Debug：`app/build/outputs/apk/debug/freedom+_1.4.0.apk`。
- R8 映射：`app/build/outputs/mapping/release/mapping.txt`。

Debug 使用调试签名，不用于覆盖正式包。工作区整理后的对外交付只保留正式 APK 及对应源码／补丁／映射；构建中间目录可重新生成。

## 检查

```powershell
& 'D:\Tools\android-sdk\build-tools\34.0.0\aapt.exe' dump badging 'app/build/outputs/apk/release/freedom+_1.4.0.apk'
& 'D:\Tools\android-sdk\build-tools\34.0.0\apksigner.bat' verify --verbose --print-certs 'app/build/outputs/apk/release/freedom+_1.4.0.apk'
```

预期包名 io.github.fplus、versionName 1.4.0、versionCode 150、assets/version 为 1.4.0-150，正式证书与原维护线一致。

[CI 校验器](<../tools/verify_ci_apk.py>)检查真实包名、版本资产、Xposed 入口及应用／系统高刷回调执行体。CI 执行 Python 和核心 JVM 测试，编译 Debug 与未签名 Release，不使用正式密钥、不自动发布。

修改 matcher 后需要递增 [DouYinMain](<../core/src/main/java/io/github/fplus/core/hook/DouYinMain.kt>) 的缓存版本；仅公开版本名称调整不改变 matcher。开发构建可追加 4 至 12 位小写十六进制后缀，发布及本地构建不传该参数。
