# 安装与激活

本文对应 FreedomPlus **v1.3.12（148）**，完整功能见[项目首页](<../README.md>)，高刷机制见[高刷新率说明](<高刷新率.md>)。

## 一、环境与作用域

- 以 **Root + LSPosed**、**64 位主抖音**为基准。其它 Xposed 框架、32 位抖音不作完整兼容保证。
- 模块最低构建要求为 **Android 7.0 / API 24**；不表示所有功能均已在该版本测试。公开 Java Surface 帧率处理要求 Android 11 及以上。

| 目标 | 包名 | 当前范围 |
|---|---|---|
| 主抖音 | `com.ss.android.ugc.aweme` | 主要功能基准 |
| 电量与性能 | `com.miui.powerkeeper` | 小米系统侧高刷，需另勾选作用域；同一个模块 APK |
| 抖音极速版 | `com.ss.android.ugc.aweme.lite` | 保留加载规则，未完成完整功能验证 |
| 火山版 | `com.ss.android.ugc.live` | 保留加载规则，未完成完整功能验证 |

极速版与火山版不使用主抖音的共享系统侧高刷开关。

## 二、安装

1. 从 [GitHub Releases](https://github.com/hsien926/FreedomPlus/releases/latest) 下载 **Release APK** 并安装。
2. 打开 LSPosed → 模块 → FreedomPlus，启用模块。
3. 作用域中勾选主抖音。需要小米系统侧高刷时，再勾选 **电量与性能**。
4. 打开一次 FreedomPlus，使模块提供方处于可启动状态。
5. 按设备系统版本，为需要保存媒体的应用授予对应存储 / 文件权限；具体入口由系统权限管理界面提供，不假定模块首页存在快捷授权按钮。
6. 从系统应用管理或 LSPosed **强制停止抖音**，再重新打开。仅从最近任务划掉应用不等同于强制停止。

同签名旧版可覆盖安装并保留配置。其它来源的 FreedomPlus 若签名不同，系统不能直接覆盖；Debug 使用另一签名，不用于覆盖 Release。

## 三、打开模块设置与日常使用

### 设置入口

- 抖音首页视频 **长按上半屏**：默认直接打开模块设置，避开左右边缘的长按快进区域。
- FreedomPlus 应用首页 → **模块设置**：跳转主抖音内的设置入口。
- 启用清爽模式后，使用所选择半屏的长按菜单 → **模块设置**。
- 旧侧边栏 / 加号弹窗入口保留，但对应界面可能随抖音版本消失；不再把“抖音设置页最底部”当作通用入口。

若“长按上半部分打开模块设置”开启，上半屏归设置入口，清爽模式菜单由下半屏响应；关闭后可自行选择清爽菜单半屏。

### 下载

1. 开启“视频 / 图文 / 音乐下载”与需要的清爽模式菜单。
2. 从长按菜单选择“下载”，或启用“分享 → 复制链接”弹出下载。
3. 在弹窗中选择视频 / 图片 / 背景音乐或文案复制，按需更改文件名及创作者目录。
4. 文件进入外置存储器 `Download/Freedom` 的分类目录；可选择弹窗或通知栏显示进度。

评论图片 / 视频与表情保存由相关页面入口提供，受目标版本页面结构影响。

### WebDAV

设置服务器地址、用户名、密码，完成连接测试后，可在下载弹窗中选择媒体的 WebDAV 选项，将下载的视频、图片或背景音乐上传至所配置服务器。

当前实现**不是模块配置备份与恢复**，也不是唯一联网功能：媒体下载、WebDAV 与属地查询均可能访问网络。WebDAV 支持多份配置历史。

### 图标与日志

- 模块应用首页右上角显示 / 隐藏图标按钮切换桌面入口；隐藏后仍可使用抖音内设置入口。
- 首页右上角旋转图标：点击播放动画，长按查看随包分发的更新日志。
- 模块设置提供类匹配日志与 DexKit 缓存清除；清除后重新启动目标应用进行定位。

## 四、高刷新率

1. 在 LSPosed 中保留主抖音作用域，小米设备另勾选 **电量与性能**。
2. 打开一次 FreedomPlus。
3. 在抖音内模块设置中打开 **解锁高刷新率（实验）**。
4. 强制停止并重开抖音。
5. 首次追加系统作用域时还需重载 PowerKeeper 主进程。整机重启可重载所有相关进程；只重开抖音不能让已运行的 PowerKeeper 加载新 Hook。

新装默认关闭；升级首次迁移主抖音内的既有状态。应用侧 Hook 按进程启动时的开关注册，改开关后需要重启抖音，不宣称全部 Hook 可以即时撤销。

关闭高刷：关闭原开关并重启抖音。若完全退出系统侧处理，再取消电量与性能作用域并重载 PowerKeeper / 重启设备。无需恢复全局刷新率键，本功能未写入这些键。

本功能不做视频补帧，仍保留省电、热限制与用户上限。详情及对照检查见[高刷新率说明](<高刷新率.md>)。

## 五、验证与排查

FreedomPlus 首页“加载成功”表示框架已加载模块；显示的抖音版本适配提示来自包内列表。“版本功能正常”只代表列表命中，不代表每个开关已验证有效。

加载失败时依次检查：

1. LSPosed 模块开关与目标包作用域。
2. 目标应用是否真正强制停止并重启。
3. 是否使用 64 位主抖音。
4. 本机版本是否符合当前功能的定位特征，参照[已知限制](<已知限制.md>)。
5. 小米系统高刷是否勾选电量与性能，且其主进程已经重载。

读取相关日志：

```bash
adb logcat -d -s Freedom+ Freedom+RefreshSystem Freedom+RefreshSync
```

提交 [Issue](https://github.com/hsien926/FreedomPlus/issues) 时附抖音版本、设备 / 系统版本、作用域、功能开关、复现步骤和必要的已脱敏日志。

## 六、数据清理与卸载

**“长按清空下载目录”同时清除模块本地配置、下载内容，并复位共享高刷开关。该操作不是覆盖升级的必要步骤。**

卸载时，先关闭模块或取消相关作用域，再重载抖音与 PowerKeeper，最后卸载模块。取消作用域本身不会从已经运行的进程中移除 Hook。

卸载模块应用不自动删除抖音私有目录中的旧配置或外置存储器 `Download/Freedom` 媒体。需要清理时，先确认已保存需要保留的文件，再使用系统文件管理或应用数据管理功能。
