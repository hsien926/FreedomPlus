# 安装与激活

---

## 一、前置条件

- Android 8.0（API 24）及以上
- 已 root 并安装 **LSPosed**
- **64 位**抖音客户端

> 为什么不建议 32 位抖音：网络上流传的历史版本大多是 32 位，模块在 32 位环境下对部分资源的处理会失败，表现为频繁崩溃。安装前可在「应用信息」中确认抖音架构。

支持的抖音包名：

| 客户端 | 包名 |
|---|---|
| 抖音主版 | `com.ss.android.ugc.aweme` |
| 抖音极速版 | `com.ss.android.ugc.aweme.lite` |
| 火山版 | `com.ss.android.ugc.live` |

---

## 二、安装步骤

### 1. 安装模块本体

从 [Releases](https://github.com/hsien926/FreedomPlus/releases) 下载 APK 并安装。系统会提示「未知来源应用」，允许即可。

**升级安装说明**：本项目发布包使用固定签名，本项目的历史版本之间可直接覆盖安装，配置不丢失。若你之前装的是**其它来源**的 FreedomPlus，由于签名不同，覆盖安装会被系统拒绝，需先卸载旧版再装。

### 2. 在 LSPosed 中启用

1. 打开 LSPosed 管理器 → 「模块」；
2. 找到 **FreedomPlus**，打开右侧开关；
3. 在「作用域」中勾选**抖音**（如使用极速版 / 火山版，对应包名也要勾选）；
4. 保存。

### 3. 授予文件权限

模块需要读写权限来加载配置、保存下载文件：

设置 → 应用管理 → 抖音 → 权限 → 授予**存储 / 文件读写**权限。

Android 11 及以上如无该权限，可在模块首页点「清空数据目录」旁的入口跳转授权页；也可通过模块首页的提示自行在系统设置中开启「所有文件访问权限」。

### 4. 重启抖音

在 LSPosed 中或从最近任务中**强制停止**抖音，然后重新打开。

## 三、验证是否生效

打开 **FreedomPlus** 应用（它是模块的设置界面，本身也可以作为独立 App 打开）：

首页「模块状态」卡片应显示：

```
LSPosed加载成功!
抖音: 40.6.0，版本功能正常
```

- `LSPosed加载成功!` 表示模块已被框架注入；
- 第二行是本机抖音版本号，以及该版本是否在随包分发的适配列表内。「版本功能正常」表示在列表内，「自行测试功能」表示未在列表内、需自行验证各项功能。

### 若显示「加载失败」

按顺序排查：

1. LSPosed 中「模块」开关是否打开；
2. 作用域是否勾选了抖音对应包名；
3. 抖音是否已强制停止并重启（勾选作用域后必须重启目标应用）；
4. 抖音是否为 64 位；
5. 抖音版本是否过低（低于 28.0.0 兼容性下降明显）。

仍无法解决时，抓取日志后提 Issue：

```bash
adb logcat -s Freedom+
```

## 四、日常使用

### 打开模块设置

三种方式：

1. 直接打开 FreedomPlus 应用；
2. 抖音 → 我 → 右上角菜单 → 设置 → 拉到最下方「FreedomPlus」；
3. 长按抖音首页视频，唤出模块菜单。

### 隐藏模块图标

模块首页右上角第一个图标可切换模块图标的显示 / 隐藏。隐藏后仍可通过上述第 2、3 种方式进入设置。

### 查看更新日志

模块首页右上角第二个图标（旋转图标）：

- **点击**：图标旋转动画；
- **长按**：显示更新日志。

本版本已移除联网检查更新，更新日志内容随 APK 分发。

### 备份配置

设置页最下方「WebDAV」可配置 WebDAV 服务器，用于备份与恢复模块配置。这是模块唯一的联网功能。

---

## 五、卸载

1. 在 LSPosed 中取消勾选抖音的作用域，或关闭模块开关；
2. 强制停止抖音；
3. 卸载 FreedomPlus 应用；
4. （可选）删除残留配置：`/data/data/com.ss.android.ugc.aweme/files/fplus/`，以及下载目录 `外置存储器/Download/Freedom`。
